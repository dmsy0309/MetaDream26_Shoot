# 카드 이미지 가이드 (CardArt)

카드 앞면의 그림 영역(희귀도 띠 아래 직사각형과 가운데 원)에 이미지를 넣는 방법입니다. 이미지가 없으면 지금처럼 영문 두 글자 문양이 나옵니다.

## 1. 규격

카드는 화면 기준 해상도 1920×1080에서 **300×480** 크기로 그려집니다. 아래 값은 모두 이 기준 픽셀입니다. 실제 값은 `Presentation/CardArt.cs`의 상수이고, `GameHud.DrawCard`가 이 상수로 그립니다.

| 부분 | 카드 안 위치 (왼쪽 위 기준) | 크기 |
|---|---|---|
| 카드 전체 | (0, 0) | 300 × 480 |
| 바깥 테두리 | 사방 6 | |
| 희귀도 띠 | (6, 6) | 288 × 44 |
| **그림 영역 (직사각형)** | **(20, 60)** | **260 × 112** (가로:세로 = 65:28 ≈ 2.32:1) |
| 문양 원 (바깥 고리) | 그림 영역 중앙 (150, 116) | 지름 96 |
| 문양 원 (안쪽 원) | 같은 중앙 | 지름 80 |
| 글자 문양 | 같은 중앙 | 글자 상자 100 × 64 (글자 크기 36, 3글자 이상 26) |
| 효과 표시 점 | 그림 영역 오른쪽 아래, 중심 (오른쪽 끝 − 16 − 18×i, 아래 끝 − 14) | 지름 12 (카드 `effects` 개수만큼, 이미지 위에 그려짐) |
| 그림 영역 아래 | 제목·설명·능력치 줄 (y 172부터) | |

화면에서 실제로 보이는 크기는 창 크기에 비례합니다. 1600×900 창에서는 0.83배이고, 4K 화면에서는 2배입니다. 카드 선택 화면에서 고른 카드는 1.15배로 커집니다(4K에서는 그림 영역이 약 598×258 실제 픽셀).

## 2. 권장 이미지

| 모드 | 그려지는 곳 | 권장 크기 | 최소 | 형식 |
|---|---|---|---|---|
| `fill` (기본) | 그림 영역 260×112 전체를 덮음. 원과 글자는 그리지 않음 | **1040 × 448** (4배) | 520 × 224 | PNG 또는 JPG |
| `icon` | 원 안쪽 80×80 정사각형에 비율 유지로 맞춤. 배경 줄무늬와 원은 그대로 | **320 × 320** (4배) | 160 × 160 | 투명 배경 PNG |

- `fill` 이미지 비율이 65:28과 다르면 가운데를 기준으로 잘려 채워집니다(ScaleAndCrop). 중요한 내용은 가운데에 두세요.
- `fill` 모드에서는 그림 영역 맨 아래 3픽셀(이미지 기준 12픽셀)에 희귀도 색 선이 덮입니다.
- 선택하지 않은 카드는 어둡게 덮이므로(55%) 너무 어두운 그림은 피하세요. 화면이 어두운 발표장이라면 밝고 대비가 강한 그림이 잘 보입니다.
- 가이드 템플릿: [card-art-template-fill.png](card-art/card-art-template-fill.png) (격자 1칸 = 기준 10픽셀, 노란 원 = 문양 고리, 흰 원 = icon 영역), [card-art-template-icon.png](card-art/card-art-template-icon.png).

## 3. 이미지 넣는 곳

이미지 이름은 기본적으로 **카드 id**입니다. 예를 들어 `rounds_homing` 카드라면 `rounds_homing.png`입니다.

| 위치 | 빌드 필요 | 우선순위 |
|---|---|---|
| 게임 폴더 `Content/CardArt/<이름>.png` (`.jpg`·`.jpeg`도 가능) — Windows: exe 옆, macOS: .app 옆, `-content <폴더>`로 지정 가능 | 아니오 | 1 |
| `Assets/Reimplementation/Resources/Content/CardArt/<이름>.png` | 예 | 2 |

- 내장 폴더에 넣은 PNG는 `Editor/CardArtImporter.cs`가 원본 크기 유지(2의 거듭제곱으로 늘리지 않음), sRGB, 밉맵, 최대 2048로 자동 설정합니다.
- 카드 JSON을 바꾸지 않아도 같은 이름의 파일만 넣으면 표시됩니다.

## 4. 카드 JSON (선택)

```json
{
  "id": "frost_rounds",
  "image": "ice_crystal",
  "imageMode": "icon"
}
```

| 키 | 의미 |
|---|---|
| `image` | 사용할 이미지 파일 이름(확장자·폴더 없이). 생략하면 카드 id. 여러 카드가 같은 그림을 쓸 때 사용 |
| `imageMode` | `"fill"`(기본) 또는 `"icon"` |

검증 메시지:

- `image '../x' must be a file name …` (오류): 이름에 폴더나 확장자를 쓸 수 없습니다. 영문/숫자/`_`/`-`만 됩니다. 카드 파일이 CardArt 폴더 밖의 파일을 읽지 못하게 막는 규칙입니다.
- `imageMode must be "fill" or "icon"` (오류)
- `image 'x' not found …` (경고): `image`를 직접 적었는데 파일이 없으면, 카드는 글자 문양으로 표시됩니다.

## 5. 확인 방법

1. 설정에서 디버그 모드를 켜고 **콘텐츠 도감 → 카드**를 엽니다. 상세 화면의 "이미지:" 줄에 불러온 파일(외부/내장, 픽셀 크기) 또는 넣어야 할 경로가 나옵니다.
2. 게임 폴더 이미지를 바꾼 뒤 타이틀에서 F5(콘텐츠 리로드)를 누르면 다시 불러옵니다.
3. 실행 인자 `-codex cards:<검색어>`를 쓰면 도감의 해당 카드를 바로 엽니다.

## 6. 멀티플레이 참고

- 이미지는 각 컴퓨터에서만 그리는 화면 요소라 게임 진행에는 영향이 없습니다. 네트워크 형식은 바뀌지 않았습니다.
- 카드 JSON에 `image`/`imageMode`를 추가하면 콘텐츠 해시가 바뀝니다. 서버와 참가자의 카드 JSON은 지금처럼 같아야 합니다.
- 이미지 파일만 다르면 접속은 되지만, 사람마다 다른 그림이 보입니다. 같은 `Content` 폴더를 함께 나눠 주세요.
